Context & Domain Constraints
Target System: University HR Management System Database Type: SQL Server (Transact-SQL) Integration Target: Spring Boot API

1. Data Types & Enums Mapping
Booleans: SQL bit maps to Java Boolean.

Strings: SQL varchar(50)/char(11) maps to Java String.

Dates: SQL date maps to Java LocalDate.

Time: SQL time (check-in/out) maps to Java LocalTime.


IDs: All IDs are identity(1,1)  and int.

2. Domain Rules (Validation Logic)

Rating Range: 1 to 5.


Document Status: valid, expired.


Leave Status: approved, rejected, pending (Default: pending).


Deduction Types: unpaid, missing_hours, missing_days.


Deduction Status: pending, finalized (Default: pending).


Attendance Status: absent, attended (Default: Absent).


Contract Type: full_time, part_time.


Employment Status: active, onleave, notice_period, resigned.


Medical Leave Type: sick, maternity.


Work Hours: Full-time requirement is 8 hours/day.


Salary Calculation: base_salary + (years_of_experience * 0.01 * base_salary).


Overtime Calculation: (employee_salary / 22 / 8) * (overtime_factor * extra_hours / 100).
